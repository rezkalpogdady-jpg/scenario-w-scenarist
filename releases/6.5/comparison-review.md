# مراجعة مقارنة تحديث 6.5 مع 6.4

## نطاق المقارنة
- تمت مقارنة HTML تحديث 6.5 مع ملف HTML المحفوظ لتحديث 6.4 (نسخة تنظيف PDF عند فشل الاستبدال).
- الفروق الوظيفية في HTML محدودة إلى:
  1. تعديل طريقة إظهار نموذج استعادة كلمة المرور ورسالة تغييرها.
  2. عدم تسجيل خروج العضو العادي تلقائيًا عند محاولة دخول لوحة الإدارة بحساب غير إداري.
  3. تبسيط تنظيف ملف PDF الجديد عند فشل الحفظ.
- لم تتغير بنية أقسام الموقع الرئيسية أو أسماء الأقسام في المقارنة النصية.

## فحوصات ساكنة
- استخراج 15 كتلة script من HTML؛ 12 غير فارغة.
- اجتازت كتل JavaScript غير الفارغة فحص الصياغة عبر `node --check`.
- لم يظهر مفتاح `service_role` أو `sb_secret_` في HTML أو SQL؛ ورود عبارة service_role في تعليق تحذيري فقط.
- SQL Migration لا يحتوي على DROP TABLE أو DELETE FROM أو DROP FUNCTION. ورود TRUNCATE هو ضمن REVOKE TRUNCATE فقط.
- تمت مراجعة السياسات التقييدية لملفات الأعضاء وأعمالهم وStorage، بما فيها منع anon من قراءة bucket الخاص.

## حدود مهمة
- لم يتم تنفيذ SQL على Supabase الحي.
- لم يتم اختبار حساب عضو أو مدير أو زائر على قاعدة البيانات الحية.
- لم يتم اختبار رفع الملفات أو قراءتها أو حذفها على Storage الحي.
- لم يتم نشر HTML على الفرع الرئيسي main أو على الموقع المباشر.
- لذلك فهذا فحص ساكن فقط وليس شهادة أمان نهائية.

## حالة الإصدار
- أضيفت ملفات 6.5 إلى الفرع المستقل `stage/6.5-security-review`.
- لم يُدمج الفرع في `main`، ولم تُستبدل أي نسخة سابقة.
