# تحديث 6.7 – مشروع التخرج النهائي

- إضافة مساحة مشروع تخرج لكل طالب: عنوان، نوع درامي، Logline، ملخص، معالجة، وسيناريو.
- حفظ مسودة والعودة لاستكمالها.
- إتاحة الإرسال النهائي بعد إتمام 30 محاضرة واعتماد 30 تدريبًا.
- لوحة الإدارة تعرض المشروعات وتسمح بالاعتماد أو الإعادة للتعديل مع الملاحظات.
- صلاحيات RLS: الطالب يرى ويعدل مشروعه فقط؛ الإدارة المعتمدة تراجع جميع المشروعات.
- فحص من قاعدة البيانات يمنع الإرسال النهائي قبل استكمال 30 محاضرة واعتماد 30 تدريبًا، ولا يسمح للطالب بتعديل ملاحظات الإدارة.
- لا تُصدر شهادة تلقائيًا في هذه المرحلة؛ اعتماد المشروع هو نقطة التحقق المطلوبة قبل تنفيذ نظام الشهادات.

## حالة التنفيذ

تم تطبيق Migration على مشروع Supabase المرتبط. يلزم اختبار واجهة الموقع بحساب طالب وحساب مدير قبل اعتبار الميزة جاهزة للإطلاق.
